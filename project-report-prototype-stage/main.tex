\section{Introduction}
The current prototype connects keyboard activity to a trust score on a web dashboard. This report records the modules completed, the checks performed and the work remaining at the prototype stage.

\section{Methodology and Design}
\subsection*{Implemented modules}
\renewcommand{\arraystretch}{1.2}
\begin{tabular}{@{}>{\raggedright\arraybackslash}p{3.2cm}>{\raggedright\arraybackslash}p{12.6cm}@{}}
\hline
\textbf{Module} & \textbf{Current implementation}\\
\hline
Login and interface & Flask login page, typing area, trust graph and decision history.\\
Typing measurements & Key timings, typing speed and pauses grouped into 10-second windows.\\
Model and scoring & Saved Isolation Forest model connected to a 0--100 trust score and recommendation.\\
Recorded replay & Stored feature windows can be played through the same scoring engine.\\
\hline
\end{tabular}

\section{Conclusion and Pending Work}
The completed result is a working demonstration of typing input, scoring and dashboard feedback. Re-authentication and locking are recommendations only. More recording sessions, evaluation on unseen sessions and actual response enforcement remain pending.
